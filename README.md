# THREATS_VS_VULNERABILITIES
THREATS:
Anything — person, event, or condition —
that has the potential to cause harm by
exploiting a weakness in a system.

VULNERABILITIES:
A weakness or flaw in a system that can
be exploited by a threat to cause harm.


EXAMPLE OF THREATS
-An employee receives an email from “HR
Department” asking to verify their login details
via a link.
REASON
-Phishing — an external malicious attempt to trick
a user into revealing credentials.

EXAMPLE OF VULNERABILITY
-A company server is running Windows Server
2012, which no longer receives security updates.
REASON
-Outdated/unpatched software — exploitable
weakness due to lack of updates.
